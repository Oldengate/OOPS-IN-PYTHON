Notes
------------------------------
| Magic method    | Automatically used when         |
| --------------- | ------------------------------- |
| `__init__()`    | Object is created               |
| `__str__()`     | `print(object)` / `str(object)` |
| `__len__()`     | `len(object)`                   |
| `__add__()`     | `object1 + object2`             |
| `__eq__()`      | `object1 == object2`            |
| `__lt__()`      | `object1 < object2`             |
| `__getitem__()` | `object[index]`                 |
| `__call__()`    | `object()`                      |
|  `__contains()` | `in operator on an object`      |
| `__del__()`     | Object is being destroyed       |
